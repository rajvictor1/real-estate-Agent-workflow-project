# Lead Management Workflow

A screenshot-based, consolidated specification for the lead intake, AI calling, WhatsApp, follow-up, and monitoring flow. The visual is a dark, responsive single-page guide.

## Files

- `index.html` — interactive visual workflow.
- `WORKFLOW-STEPS.md` — step-by-step explanation and screenshot coverage audit.
- `vercel.json` — static-site Vercel configuration.

## Run locally

Open `index.html` in a browser. It is a static HTML page and requires no build step.

## Publish

Import this repository into Vercel as a static project with the repository root as the project root. No framework preset, build command, or output directory is required.

## Source boundaries

The screenshots describe a proposed automation. They do not prove that a calling provider, WhatsApp Business integration, spreadsheet integration, consent, or production deployment exists. See `WORKFLOW-STEPS.md` for screenshot-explicit behavior versus added reliability safeguards.
